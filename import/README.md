# import/

Lists made from outside sources, to be used when the real book list is chosen. They are not used by the site yet.

- `dda-files.csv`: every file in the public Dhamma-Dāna Archive folder on Google Drive (one row per file, with folder path, last-modified date, id and link). Made on 2026-10-23 with `tools/list-drive-folder.py`.
- `dda-books.csv`: the same list with a PDF and an EPUB of the same name merged into one row.

The folder "Upload folder - Add your favorite books!" is open for other people to add to, so check what is in it before using it.
